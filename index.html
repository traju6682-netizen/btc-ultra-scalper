આ સિસ્ટમ કેવી રીતે સિગ્નલ આપે છે?

BUY માટે EMA 9 > EMA 21, RSI ≥ 55 અને MACD line > signal line. SELL માટે EMA 9 < EMA 21, RSI ≤ 45 અને MACD line < signal line. આ સરળ ફિલ્ટર છે—દરેક સિગ્નલ નફાકારક નહીં હોય અને sideways marketમાં ખોટા સિગ્નલ આવી શકે.

મહત્ત્વપૂર્ણ: આ ફક્ત સિગ્નલ/શૈક્ષણિક ટૂલ છે. CoinDCXમાં ઓર્ડર આપતું નથી. API key/secretની જરૂર નથી. પહેલાં paper trading કરો; 5x–7x leverageથી નુકસાન ઝડપથી વધી શકે છે.

જો ડેટા ન આવે, તો Binance API તમારા નેટવર્ક/પ્રદેશમાં બ્લોક હોઈ શકે. Futures API પહેલાં અજમાય છે; નિષ્ફળ થાય તો Spot API fallback થાય છે, જેના ભાવ Futuresથી થોડા અલગ હોઈ શકે.
